🧮 Çarpanlara Ayırma ve Oran-Orantı

Özdeşliklerle çarpanlara ayırma ve oran-orantı problemlerinin pratik çözüm yolları.

📚 KPSS Matematik · 7. Konu ⏱️ 15 dk okuma ✅ 15 soruluk test

Özdeşlikler

(a + b)² = a² + 2ab + b²     (a − b)² = a² − 2ab + b²
a² − b² = (a − b)(a + b)     (a + b)² − (a − b)² = 4ab
  • a + b = 7 ve a · b = 10 ise a² + b² = (a + b)² − 2ab = 49 − 20 = 29.
  • 101² − 99² = (101 − 99)(101 + 99) = 2 · 200 = 400.
  • a − b = 3 ve a² − b² = 21 ise a + b = 21 / 3 = 7.

Çarpanlara Ayırma Yöntemleri

Ortak paranteze alma3a + 3b = 3(a + b); x² + 5x = x(x + 5).
İki kare farkıx² − 9 = (x − 3)(x + 3).
Tam karex² + 6x + 9 = (x + 3)²; x² − 10x + 25 = (x − 5)².
x² + bx + cÇarpımı c, toplamı b olan iki sayı bulunur: x² + 5x + 6 = (x + 2)(x + 3) (2 · 3 = 6, 2 + 3 = 5).

Oran ve Orantı

Aynı birimden iki çokluğun bölümüne oran, iki oranın eşitliğine orantı denir.

a/b = c/d ise a · d = b · c (içler-dışlar çarpımı)
  • x/4 = 9/6 → 6x = 36 → x = 6.
  • a/b = 2/3 ve a + b = 25 ise a = 2k, b = 3k, 5k = 25 → k = 5 → a = 10.
  • Bileşik orantı: a/2 = b/3 = c/5 = k ve a + b + c = 50 ise 10k = 50 → k = 5 → c = 25.

Doğru ve Ters Orantı

OrantıTanımÖrnek
Doğru orantıBiri artarken diğeri aynı oranda artar; x/y = k (sabit).5 kg elma 60 TL ise 8 kg elma 8 · 12 = 96 TL.
Ters orantıBiri artarken diğeri aynı oranda azalır; x · y = k (sabit).6 işçi bir işi 10 günde yaparsa 15 işçi 6 · 10 / 15 = 4 günde yapar.
  • (a ± b)² = a² ± 2ab + b²; a² − b² = (a − b)(a + b).
  • a² + b² = (a + b)² − 2ab; (a + b)² − (a − b)² = 4ab.
  • x² + bx + c ifadesinde çarpımı c, toplamı b olan iki sayı aranır.
  • a/b = c/d ise ad = bc.
  • Oranlı çokluklarda k sabiti kullanılır: a = 2k, b = 3k.
  • Doğru orantıda bölüm, ters orantıda çarpım sabittir.
