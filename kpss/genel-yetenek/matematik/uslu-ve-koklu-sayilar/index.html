Üs Kuralları

KuralÖrnek
a⁰ = 1 (a ≠ 0), a¹ = a7⁰ = 1
aᵐ · aⁿ = aᵐ⁺ⁿ2³ · 2⁴ = 2⁷ = 128
aᵐ : aⁿ = aᵐ⁻ⁿ2¹⁰ : 2⁸ = 2² = 4
(aᵐ)ⁿ = aᵐ·ⁿ(3²)³ = 3⁶ = 729
(a · b)ⁿ = aⁿ · bⁿ(2 · 5)³ = 10³ = 1000

Tabanlar farklıysa önce ortak tabana çevrilir: 4³ : 2⁴ = 2⁶ : 2⁴ = 2² = 4.

Negatif Taban ve Negatif Üs

  • Negatif sayının çift kuvveti pozitif, tek kuvveti negatiftir: (−2)⁴ = 16, (−2)³ = −8.
  • −2⁴ ile (−2)⁴ farklıdır: −2⁴ = −16, (−2)⁴ = 16.
  • Negatif üs, tabanın çarpmaya göre tersini alır: a⁻ⁿ = 1/aⁿ → 5⁻² = 1/25.
  • Ondalık sayılar 10'un kuvvetiyle yazılabilir: 0,001 = 10⁻³; 3000 = 3 · 10³.

Üslü Denklemler

Tabanlar eşitlenir, ardından üsler eşitlenir (taban 0, 1 ve −1 dışında).

  • 2ˣ = 32 → 2ˣ = 2⁵ → x = 5
  • 3ˣ⁺¹ = 81 → 3ˣ⁺¹ = 3⁴ → x + 1 = 4 → x = 3

Köklü Sayılar

KuralÖrnek
√(a²) = |a|x = −5 ise √(x²) = 5
√a · √b = √(a · b)√8 · √2 = √16 = 4
√a : √b = √(a/b)√18 : √2 = √9 = 3
Kök dışına çıkarma: √(a² · b) = a√b√12 = 2√3; √50 = 5√2
Toplama: kök içleri aynı olmalı√12 + √27 = 2√3 + 3√3 = 5√3

Paydayı Rasyonel Yapma ve Rasyonel Üs

  • Paydada kök varsa pay ve payda aynı kökle çarpılır: 6/√3 = 6√3/3 = 2√3.
  • Rasyonel üs: ⁿ√(aᵐ) = aᵐ/ⁿ → ∛27 = 27¹/³ = 3; √16 = 4.
  • Aynı tabanlı sayılar çarpılırken üsler toplanır, bölünürken çıkarılır; kuvvetin kuvvetinde üsler çarpılır.
  • a⁰ = 1; a⁻ⁿ = 1/aⁿ.
  • Negatif sayının çift kuvveti pozitif, tek kuvveti negatiftir; −2⁴ ≠ (−2)⁴.
  • Üslü denklemlerde tabanlar eşitlenir, sonra üsler eşitlenir.
  • √(a²) = |a|; √a · √b = √(ab); kök içleri aynıysa toplanır.
  • Paydadaki kök, pay ve payda aynı kökle çarpılarak kaldırılır.
  • ⁿ√(aᵐ) = aᵐ/ⁿ.
