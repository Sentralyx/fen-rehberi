🟰 Denklem Çözme

Birinci dereceden denklemlerden denklem sistemlerine ve ikinci dereceden denklemlere adım adım çözüm yöntemleri.

📚 KPSS Matematik · 8. Konu ⏱️ 15 dk okuma ✅ 15 soruluk test

Birinci Dereceden Bir Bilinmeyenli Denklemler

ax + b = 0 (a ≠ 0) biçimindeki denklemlerdir. Bilinmeyenler bir tarafa, sayılar diğer tarafa toplanır.

  • 3x − 7 = 11 → 3x = 18 → x = 6
  • 2(x + 3) = 5x − 9 → 2x + 6 = 5x − 9 → 15 = 3x → x = 5
  • 4(x − 1) − 2(x + 1) = 0 → 2x − 6 = 0 → x = 3

Kesirli Denklemler

Paydalar eşitlenir veya her iki taraf paydaların EKOK'u ile çarpılarak paydalardan kurtulunur.

  • x/3 + x/6 = 5 → (2x + x)/6 = 5 → 3x = 30 → x = 10
  • (x − 1)/2 = (x + 2)/5 → 5(x − 1) = 2(x + 2) → 3x = 9 → x = 3
  • 1/x + 1/(2x) = 3/4 → 3/(2x) = 3/4 → 2x = 4 → x = 2 (paydayı sıfır yapan değerler çözüm olamaz)

İki Bilinmeyenli Denklem Sistemleri

Yok etme yöntemiDenklemler taraf tarafa toplanarak veya çıkarılarak bir bilinmeyen yok edilir: x + y = 10 ve x − y = 4 → toplanınca 2x = 14 → x = 7, y = 3.
Yerine koyma yöntemiBir denklemden bilinmeyenlerden biri çekilip diğerine yazılır: x − y = −1 → x = y − 1; 2x + 3y = 13 → 2(y − 1) + 3y = 13 → 5y = 15 → y = 3, x = 2.

İkinci Dereceden Denklemler

ax² + bx + c = 0 (a ≠ 0) biçimindeki denklemlerdir. KPSS'de genellikle çarpanlara ayırma ile çözülür.

  • x² − 5x + 6 = 0 → (x − 2)(x − 3) = 0 → x = 2 veya x = 3
  • x² − 16 = 0 → (x − 4)(x + 4) = 0 → x = 4 veya x = −4
  • x² = 3x → x² − 3x = 0 → x(x − 3) = 0 → x = 0 veya x = 3 (her iki taraf x'e bölünürse x = 0 kökü kaybedilir!)
Kökler toplamı = −b/a     Kökler çarpımı = c/a

Özel Durumlar

  • Özdeşlik: Denklem her x değeri için sağlanıyorsa iki taraftaki katsayılar eşittir: ax + 3 = 2x + b her x için doğruysa a = 2, b = 3.
  • Çözümsüz denklem: 3x + 2 = 3x + 5 → 2 = 5 (çelişki); çözüm kümesi boş kümedir.
  • Sonsuz çözüm: 2x + 4 = 2(x + 2) her x için doğrudur; çözüm kümesi tüm reel sayılardır.
  • Birinci dereceden denklemlerde bilinmeyenler bir tarafa, sayılar diğer tarafa toplanır.
  • Kesirli denklemlerde paydalar EKOK ile çarpılarak kaldırılır; paydayı sıfır yapan değer çözüm olamaz.
  • Denklem sistemleri yok etme veya yerine koyma yöntemiyle çözülür.
  • İkinci dereceden denklemler çarpanlara ayrılarak çözülür; kökler toplamı −b/a, çarpımı c/a'dır.
  • Bir tarafı x'e bölmek x = 0 kökünü kaybettirebilir.
  • Her x için doğru olan denklemde katsayılar eşittir; çelişkili denklemin çözüm kümesi boştur.
