⚖️ Basit Eşitsizlikler ve Mutlak Değer

Eşitsizliklerde işlem kuralları, aralık bulma ve mutlak değerli denklem ve eşitsizliklerin çözümü.

Eşitsizliğin Özellikleri

  • Eşitsizliğin her iki tarafına aynı sayı eklenir veya çıkarılırsa yön değişmez.
  • Her iki taraf pozitif bir sayıyla çarpılır veya bölünürse yön değişmez.
  • Her iki taraf negatif bir sayıyla çarpılır veya bölünürse yön değişir.

Örnek: −2x + 3 > 7 → −2x > 4 → (−2'ye bölünür, yön değişir) x < −2.

Örnek: 3 ≤ 2x − 1 < 9 → 4 ≤ 2x < 10 → 2 ≤ x < 5.

Aralık Bulma

  • Toplama: Aynı yönlü eşitsizlikler taraf tarafa toplanabilir: 1 < x < 3 ve 2 < y < 5 ise 3 < x + y < 8.
  • Çıkarma ve çarpma: Taraf tarafa çıkarma ve çarpma yapılmaz; uç değerler denenerek en küçük ve en büyük değerler bulunur.
  • Kare alma: Aralık 0'ı içeriyorsa karenin en küçük değeri 0'dır: −2 < x < 3 ise 0 ≤ x² < 9.
  • Tam sayı değerleri: 2 < x < 5 aralığında x'in tam sayı değerleri 3 ve 4'tür.

Mutlak Değer

Bir sayının sayı doğrusunda sıfıra olan uzaklığına o sayının mutlak değeri denir ve |x| ile gösterilir.

x ≥ 0 ise |x| = x     x < 0 ise |x| = −x
  • Mutlak değer hiçbir zaman negatif değildir: |x| ≥ 0.
  • |a · b| = |a| · |b|; |−a| = |a|.
  • |x − a|, sayı doğrusunda x ile a arasındaki uzaklıktır.
  • Örnek: x < 0 ise |x| + x = −x + x = 0.
  • Örnek: x < y ise |x − y| = y − x.

Mutlak Değerli Denklem ve Eşitsizlikler

İfadeÇözümÖrnek
|x| = a (a > 0)x = a veya x = −a|x − 2| = 5 → x = 7 veya x = −3
|x| < a−a < x < a|x| < 3 → −3 < x < 3

Mutlak değerin içi belirli bir aralıkta işaretli olduğunda mutlak değer kaldırılır: −1 < x < 2 ise |x + 1| + |x − 2| = (x + 1) + (2 − x) = 3.

  • Eşitsizlik negatif sayıyla çarpılır veya bölünürse yön değişir.
  • Aynı yönlü eşitsizlikler taraf tarafa toplanabilir; çarpma ve çıkarmada uç değerler denenir.
  • Aralık 0'ı içeriyorsa karenin en küçük değeri 0'dır.
  • Mutlak değer uzaklıktır ve hiçbir zaman negatif değildir.
  • |x| = a ise x = ±a; |x| < a ise −a < x < a; |x| > a ise x > a veya x < −a.
  • Mutlak değer, içinin işaretine göre kaldırılır: x < 0 ise |x| = −x.
